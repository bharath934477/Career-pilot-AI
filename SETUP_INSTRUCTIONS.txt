CAREER ADVISOR APPLICATION - SETUP INSTRUCTIONS
===============================================

WHAT WE'VE DONE:
---------------

1. Modified graduate.html to send form data to the backend instead of using localStorage
2. Updated server.js to properly handle graduate registration
3. Created a .env file for environment variables
4. Created package.json for dependency management
5. Created README.md with detailed setup instructions

WHAT YOU NEED TO DO TO RUN THE APPLICATION:
------------------------------------------

1. INSTALL NODE.JS:
   - Download and install Node.js (version 14 or higher) from https://nodejs.org/
   - This will also install npm (Node Package Manager)

2. INSTALL MONGODB:
   - Download and install MongoDB Community Server from https://www.mongodb.com/try/download/community
   - Follow the installation instructions for Windows

3. INSTALL PROJECT DEPENDENCIES:
   - Open Command Prompt or PowerShell
   - Navigate to the project folder: 
     cd "c:\Users\sudharson.A\Desktop\new project"
   - Run: npm install

4. START MONGODB SERVICE:
   - Make sure MongoDB is running as a service
   - Or start it manually with: mongod

5. START THE SERVER:
   - In the project folder, run: npm start
   - The server will start on http://localhost:5000

6. TEST THE APPLICATION:
   - Open graduate.html in your browser
   - Fill in the form and submit
   - Data will now be stored in MongoDB instead of localStorage

TECHNICAL DETAILS:
------------------

- Form data from graduate.html is sent to http://localhost:5000/api/register
- Data is stored in MongoDB in the "graduatedb" database
- User information is saved in the "users" collection
- The form collects: name, email, password, course, and role

If you encounter any issues, please check the README.md file for detailed instructions.

ADMIN PAGE
----------
Sign in from the Student or Graduate login page with the admin email + password.
You are redirected to admin.html (it is not linked anywhere on the site).
Set your own credentials in .env before deploying:
    ADMIN_EMAIL=you@example.com
    ADMIN_PASSWORD=a-strong-password
Data is stored separately: MongoDB collections "students" and "graduates",
or (without MongoDB) data/students.json and data/graduates.json.
